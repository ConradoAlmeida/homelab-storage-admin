API de envio

Um cliente envia o magnet com o token guardado neste painel. O TORRENT_API_TOKEN do host.env só grava o primeiro valor. O destino é o id ou o nome da biblioteca, como Filmes. A categoria no qBittorrent fica jellyfin. 

curl -X POST https://homelab.conradhub.com/api/torrents/ \
  -H "Authorization: Bearer $TORRENT_API_TOKEN" \
  -d '{"magnet":"magnet:?xt=urn:btih:...","library":"Filmes"}'

201 devolve o nome da biblioteca. 409 significa que o torrent já existe na lista. 400 recusa o magnet ou a pasta. 503 é agente ou qBittorrent parado. Token vazio responde 404. As pastas saem em GET /api/torrents/bibliotecas/.
